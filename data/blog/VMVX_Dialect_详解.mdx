## 1. 概述

VMVX (Virtual Machine-based Linear Algebra eXtensions) Dialect 是 **IREE VM 的向量扩展**，提供线性代数微内核库功能。

### 设计定位

VMVX 是一个**参考实现 Dialect**，表示基于 IREE VM 的简单线性代数模块，在运行时作为库使用。

**关键特性**:
- **1:1 映射** - Dialect 中的 ops 与运行时模块中的导出函数大致一一对应
- **参考实现** - 提供可移植的线性代数微内核实现
- **无硬件加速时的后备** - 当没有特定后端支持时使用
- **调试和测试** - 用于验证其他后端的正确性

### 与 VM Dialect 的关系

VMVX ops 是 VM 的**扩展操作**，被编译为对运行时微内核库的函数调用，而不是原生 VM 字节码指令。

### 查看完整操作列表

完整的导出函数列表见 `vmvx.imports.mlir` 文件。

## 2. 核心概念

### 2.1 微内核架构

VMVX 采用**微内核架构**：
- 提供基本线性代数操作的高度优化实现
- 这些操作作为构建块用于更复杂的计算
- 运行时动态链接和调用

### 2.2 缓冲区模型

VMVX 操作在抽象缓冲区上工作：
- **主机缓冲区** - CPU 可访问的内存
- **设备缓冲区** - 加速器内存（如果适用）
- **非连续缓冲区** - 支持跨步和切片操作

VMVX 支持的元素类型：

## 5. 在编译 Pipeline 中的位置

VMVX Dialect 位于编译 Pipeline 的**代码生成阶段**，作为可选的后端目标：

```
Flow → Stream → HAL → CodeGen → { LLVM / SPIRV / **VMVX** }
```

### VMVX Pipeline 阶段

| 顺序 | Pass 名称 | 说明 |
|---|---|---|
| 1 | `VMVXSelectLoweringStrategyPass` | 选择 VMVX lowering 策略 |
| 2 | `VMVXLowerExecutableTargetPass` | 降低可执行目标 |
| 3 | `VMVXLowerLinalgMicrokernelsPass` | 降低 Linalg 微内核 |
| 4 | `VMVXAssignConstantOrdinalsPass` | 分配常量序号 |
| 5 | `VMVXLinkExecutablesPass` | 链接可执行文件 |

### 典型使用场景

| 场景 | 说明 |
|---|---|
| **调试模式** | 使用 VMVX 进行快速原型开发和调试 |
| **无硬件加速** | 在没有 GPU 或专用加速器的系统上运行 |
| **参考验证** | 用 VMVX 结果验证其他后端的正确性 |
| **小模型** | 对小模型来说 VMVX 已经足够快 |
| **可移植性** | 需要在多种平台上无需重新编译运行 |

## 总结

VMVX Dialect 是 IREE 的**可移植线性代数微内核层**：

- ✅ IREE VM 的向量扩展
- ✅ ops 与运行时模块导出函数 1:1 对应
- ✅ 提供参考实现
- ✅ 支持整数和浮点数类型
- ✅ 包含基本线性代数操作（matmul、conv、reduce 等）
- ✅ 作为无硬件加速时的后备选项
- ✅ 用于调试和验证其他后端

VMVX 的设计哲学是**可移植优先**，在任何可以运行 IREE VM 的地方都可以使用，是 IREE 多后端支持的关键组成部分。
