## 1. IREE 自有 Dialect 列表

IREE 编译器共定义了 **19 个** 自定义 Dialect：

| Dialect 名称 | 命名空间 | 定义文件 | 主要用途 |
|---|---|---|---|
| `util` | `IREE::Util` | `Dialect/Util/IR/UtilBase.td` | IREE 各子 dialect 通用的类型与工具 op |
| `flow` | `IREE::Flow` | `Dialect/Flow/IR/FlowBase.td` | 建模执行数据流与分区（dispatch region） |
| `stream` | `IREE::Stream` | `Dialect/Stream/IR/StreamDialect.td` | 显式异步调度执行，位于 flow 与 hal 之间 |
| `hal` | `IREE::HAL` | `Dialect/HAL/IR/HALDialect.td` | 硬件抽象层（Vulkan-like，无图形部分） |
| `vm` | `IREE::VM` | `Dialect/VM/IR/VMBase.td` | 抽象虚拟机，可序列化为字节码或继续 lower |
| `vmvx` | `IREE::VMVX` | `Dialect/VMVX/IR/VMVXBase.td` | VM 向量扩展/微内核库方言 |
| `iree_linalg_ext` | `IREE::LinalgExt` | `Dialect/LinalgExt/IR/LinalgExtBase.td` | Linalg 非结构化/实验性扩展 |
| `iree_tensor_ext` | `IREE::TensorExt` | `Dialect/TensorExt/IR/TensorExtBase.td` | Tensor 方言实验性扩展 |
| `iree_encoding` | `IREE::Encoding` | `Dialect/Encoding/IR/EncodingBase.td` | 张量编码属性与相关 op（data-tiling） |
| `iree_codegen` | `IREE::Codegen` | `Codegen/Dialect/Codegen/IR/IREECodegenDialect.td` | 代码生成通用属性与状态 |
| `iree_cpu` | `IREE::CPU` | `Codegen/Dialect/CPU/IR/IREECPUDialect.td` | CPU 代码生成专用属性/op |
| `iree_gpu` | `IREE::GPU` | `Codegen/Dialect/GPU/IR/IREEGPUDialect.td` | GPU 代码生成专用属性/op |
| `iree_map` | `IREE::Map` | `Codegen/Dialect/Map/IR/IREEMapBase.td` | 描述层次化坐标映射的 map 代数 |
| `pcf` | `IREE::PCF` | `Codegen/Dialect/PCF/IR/PCFBase.td` | 并行控制流（Parallel Control Flow） |
| `iree_vector_ext` | `IREE::VectorExt` | `Codegen/Dialect/VectorExt/IR/VectorExtBase.td` | Vector 方言实验性扩展 |
| `hal_inline` | `IREE::HAL::Inline` | `Modules/HAL/Inline/IR/HALInlineBase.td` | 进程内同步 HAL 互操作运行时模块 |
| `hal_loader` | `IREE::HAL::Loader` | `Modules/HAL/Loader/IR/HALLoaderBase.td` | 动态加载可执行文件并调度 |
| `io_parameters` | `IREE::IO::Parameters` | `Modules/IO/Parameters/IR/IOParametersBase.td` | 外部参数资源管理 API |
| `check` | `IREE::Check` | `Modules/Check/IR/CheckBase.td` | 测试断言 dialect |

### Dialect 注册入口

- **核心 Dialect**: `Tools/init_iree_dialects.h` - 注册前 18 个 Dialect
- **模块 Dialect**: `Tools/init_compiler_modules.h` - 注册 `check`

## 2. Pass 总览

IREE 编译器共定义了 **486 个** 自定义 Pass，按组件分类如下：

| 组件 | Pass 数量 | 主要目录 |
|---|---|---|
| Codegen | 243 | `Codegen/Common/`, `Codegen/LLVMCPU/`, `Codegen/LLVMGPU/`, `Codegen/SPIRV/`, `Codegen/VMVX/` |
| Dialect 转换 | 152 | `Dialect/{Flow,Stream,HAL,Util,VM,VMVX,LinalgExt,TensorExt}/Transforms/` |
| DispatchCreation | 31 | `DispatchCreation/` |
| GlobalOptimization | 22 | `GlobalOptimization/` |
| Preprocessing | 15 | `Preprocessing/Common/` |
| InputConversion | 9 | `InputConversion/Common/` |
| Modules | 8 | `Modules/HAL/Inline/`, `Modules/HAL/Loader/`, `Modules/IO/Parameters/` |
| Bindings | 3 | `Bindings/Native/`, `Bindings/TFLite/` |
| Transforms | 2 | `Transforms/` |
| ConstEval | 1 | `ConstEval/` |
| **合计** | **486** | |
